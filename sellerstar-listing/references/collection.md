# 用塞星官方插件采集

## 安装与登录

1. 在已登录的 [塞星商品采集](https://portal.safesellai.com/collection) 点「下载采集插件」。解压 ZIP，找到包含 `manifest.json` 的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。开启开发者模式，选「加载已解压的扩展程序」，选择该文件夹。可在扩展菜单固定「塞星铺货AI 采集助手」。优先使用门户提供的当前版本和安装指引。
3. 保持同一个浏览器配置登录指定塞星工作区。在扩展「设置」核对状态、服务器地址及账号。正式门户地址是 `https://portal.safesellai.com`。登录、扩展权限和平台人工验证由操作者按页面完成。

## 单品或批量

| 用户要做什么 | 插件和门户中怎样做 |
| --- | --- |
| 采当前商品 | 打开支持的来源站点详情页，确认当前主品或变体。点浮窗采集按钮，或从浏览器工具栏点「抓取当前页」 |
| 批量采集 | 在支持的网站列表勾选用户指定的商品，点「批量采集」。给了多个详情链接时，优先用插件的「链接批量」入口，按当前插件说明操作 |
| 带变体 | 在可用的采集方式中核对「只采本体（不带变体）」或同义选项。需要变体时保留变体采集；只要本体时才选只采本体 |
| 只采指定子 SKU | 优先采该子 SKU 的实际详情页。目标是有限子集时，核对门户是否有子变体选择以及保存后的 SKU 清单 |
| 恢复本地队列 | 插件在本地队列显示未同步时，先核对塞星连接和当前账号，恢复后按「同步到采集箱」推送，去门户读回实际记录 |

根据插件结果区分已同步、已存在、留在本地队列和失败。清掉门户筛选后，按来源链接、ASIN、商品或 SKU 读回采集记录和当前工作区。重复商品优先复用原记录。只有已核对的采集结果才能继续创建铺货任务。响应不明时先查该工作区采集箱和队列，避免重复采集。

智能体如果只能查看普通网页，使用能直接操作的商品页插件按钮。工具栏弹窗、安装、浏览器权限或验证码需人工完成时，明确交代当前页面、待点击的入口和待采的商品。用户完成后继续从门户读回结果并推进原任务。不要切换工作区代替排查。

## 核对变体和来源

- 逐 SKU 核对身份、图片、报价、币种和库存。Amazon 实际报价只对应该页面选中的 ASIN。来源数量未知、商品确实缺货与人工固定库存 0 分开记录。
- 只有缩略图时先查看采集记录和后台补图进度。必要时回正确变体详情页重新核对来源图。仅在能证明是同一规格时才共用图库。用户已手工选择的图片继续沿用，修改时通过产品保存入口。
- 适用来源以当前官方插件支持列表和按钮为准。沃尔玛、大建云仓、Doba 或其他来源的采集方式可能不同。遇到认证、限流或离线时保留原链接和确切未完成项。
